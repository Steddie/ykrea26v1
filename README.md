# Webbutveckling med React VT2026

All källkod för YH-kursen _Webbutveckling med React, 30 yhp_ för klassen YKREA26V1 på IT-högskolan.

## Källkod

Varje lektion är en egen, fristående branch och innehåller samtlig källkod från föregående branches.

## Branches

Hämta ut den branch du är intresserad av.

### Exempel

```zsh
git pull
git checkout lesson-1
cd 01-intro
```

osv.

För att köra varje lektion, börja med att;

 1. Hämta hem senaste lektionen
 2. Gå in i den senast hämtade mappen
 3. Kör 'npm install'
 4. Kör 'npm run dev'
